description=Class overrides for Project Zomboid Build 42.20.4 (game revision b0bbce05d5) that shorten chunk-streaming stalls and tighten the frame time, plus a full options tab (Options > Optimizations) and an in-game frame-time overlay (F9). Single player and multiplayer, client side only; nothing to install on a server. Works with the Steam version on Windows and Linux (both depots ship the same jar).

description=[h1]What it does[/h1]
description=Project Zomboid loads and bakes the map in chunks; on stock, the loading, baking and lighting work of a busy screen lands in the same frame and shows as stutter while driving or turning. These overrides move that work off the game thread, spread it over frames, and cache what stock recomputes every frame (puddles, rain, cutaways, light info, sound zones). Bench numbers on the repository page; the short version at 5120x2160 on an RTX 4090: driving p99 frame time 19 -> 8 ms, uncapped ~270 -> ~500 fps, thunderstorms 83 -> 188 fps.

description=[h1]How it works[/h1]
description=The launcher (ProjectZomboid64.json) searches the game folder before projectzomboid.jar, so a loose .class file with the same name as one in the jar replaces it. The item holds those files (146 entries: 37 shadowed game classes, the pzopt helper package, three Lua files for the options tab and a manifest) under [b]pzopt-classes[/b]. projectzomboid.jar is never modified. A guard compares your game revision and the sha256 of every stock class it shadows against the jar at start-up; if anything differs (another game build) it logs one line to console.txt and the game runs as stock, so a mismatch has no effect.
description=
description=[h1]Install on Windows[/h1]
description=1. Subscribe, let Steam download the item, close the game.
description=2. Open PowerShell (Start menu, type powershell) and run (adjust the drive if your Steam library is elsewhere):
description=[code]powershell -ExecutionPolicy Bypass -File "C:\Program Files (x86)\Steam\steamapps\workshop\content\108600\3805285544\mods\PZ_Optimization\42\install.ps1"[/code]
description=The script finds the game through Steam's library list, checks the revision, refuses to overwrite anything that already exists, copies the files next to the jar and records them in pzopt-installed.txt.
description=3. Launch the game from Steam. The first boot is a few seconds slower (caches are written under %USERPROFILE%\Zomboid\pzopt\). console.txt shows one "[pzopt] loaded override ... active" line per class.
description=
description=Uninstall: the same command with -Uninstall. -Status lists what is installed and whether any file changed.
description=
description=Without the script: copy the contents of the item's pzopt-classes folder into the folder that holds projectzomboid.jar (do not overwrite anything; if a file already exists you have an older install, remove it first). Removal is deleting the files listed in pzopt-files.txt.
description=
description=[h1]Install on Linux[/h1]
description=[code]bash ~/.local/share/Steam/steamapps/workshop/content/108600/3805285544/mods/PZ_Optimization/42/install.bash[/code]
description=(Steam Workshop items cannot contain .sh files, hence .bash.) Same flags: --status, --uninstall, --dir <game folder>.

description=[h1]Performance overlay (F9)[/h1]
description=[img]https://raw.githubusercontent.com/xD3I/PZ_Optimization/master/docs/workshop/images/09-performance-overlay.jpg[/img]
description=Presented frame time, p50 / p99 / p99.9 / max, 1 %-low, jitter and spikes over the last 5 s, GPU busy (GL timer query), game-thread and render-thread load, process and machine CPU, heap, a verdict line (GPU bound / game thread bound / at the cap) and the frame graph. Same numbers on Windows and Linux, no MangoHud or RivaTuner needed; every run also logs it to Zomboid/pzopt-overlay.out.
description=
description=[h1]Settings[/h1]
description=Options > Optimizations in the game (saved to Zomboid/pzopt/options.ini, applied on the next launch) has every key with a tick box, plus "Disable all (stock game)" / "Enable all". Options > Display gains an "Uncapped" framerate entry and a separate menu framerate. F9 toggles the performance overlay.
description=
description=[h1]Updates[/h1]
description=The files are built for one game revision. When the game updates, the guard turns them off (stock game, one console line) until a build for the new revision is published here; then run the installer with -Uninstall / --uninstall and again without.
