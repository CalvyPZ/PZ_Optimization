# docs/

Committed prose and generated reports. Nothing here may contain game source; edits to game
classes are described in words.

| File | What |
|---|---|
| `override-edits.md` | the authoritative prose log of every change in `src/overrides/`; extend it whenever an override changes |
| `results.md` | result of the parallel-chunk-grid-recalc work (chunk latency) |
| `baseline-findings.md` | 2026-09-14 Proton-era baseline findings |
| `native-baseline-2026-09-18.md` | harness re-validation on the native build, first frame-time baseline |
| `plan-driving-frame-time.md` | 2026-09-18 plan and driving target (p99 ≤ 10 ms, p99.9 ≤ 16.7 ms, no frame > 33 ms, jitter ≤ 1 ms); §3.1 superseded by baking, §3.3/3.4 done |
| `plan-resource-use.md` | 2026-09-19 verdict on why the uncapped game idles (Zink swap stall; NVIDIA GL is GPU-bound) |
| `plan-game-load.md` | the load after "Continue" (LoadTrace, loadtime.py) |
| `plan-vulkan-renderer.md` | plan to move from OpenGL to Vulkan |
| `plan-wayland.md` | 2026-09-19 native Wayland vs XWayland A/B: a wash at the cap, XWayland stays default |
| `plan-diagram.md` | plan at a glance |
| `proton-run-prep-2026-09-19.md` | command sequence for the pending Proton comparison |
| `windows-test.md` | installing the prebuilt class zip on a Windows depot and testing it; 2026-09-19 results of the first Windows bench (stock vs optimized, utilization) |
| `recalc-static-audit.md` | static-state audit of the recalc pass (tools/StaticAudit) |
| `benchmark-progress.html/.json` | generated by `harness/dashboard.py`; regenerate after every run |
| `media/drive-results.svg` | generated by `harness/readme-chart.py` |

Conventions: date findings in the heading, put numbers in tables, name the runs they came
from (label + timestamp under `harness/runs/`), and note resolution / renderer / zoom /
launcher so the run is comparable later. Start new work from the relevant plan's open
sections rather than re-deriving.
